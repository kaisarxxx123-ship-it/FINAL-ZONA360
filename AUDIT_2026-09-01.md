# Audit source Zona360 V2 — 1 September 2026

## Ruang lingkup

- Source Android hasil ekstraksi `Zona360_V2_FINAL_AUDITED_SOURCE.zip`.
- Konfigurasi Gradle/Android, manifest, Java native plugins, foreground location service,
  aset web terkompilasi, konfigurasi JSON/XML, dan Firebase Realtime Database rules.

## Masalah yang ditemukan dan diperbaiki

1. **Gradle wrapper tidak standar dan tidak lengkap.** Script lama mengunduh Gradle
   dengan `curl`/`wget`, sementara `gradle-wrapper.jar` tidak disertakan. Script
   wrapper diganti dengan script resmi Gradle 8.9. Sesuai kebijakan PR
   source-only, binary `gradle-wrapper.jar` tetap ada di project lokal tetapi tidak
   disertakan dalam perubahan Git; generate kembali dengan task `gradle wrapper`
   sebelum menjalankan `./gradlew` pada checkout baru.
2. **Tracking GPS tidak pernah meminta permission yang dibutuhkannya.** Plugin hanya
   menolak pemanggilan jika location belum diberikan, tidak meminta background
   location pada Android 10+, dan tidak meminta notification permission pada Android
   13+. Alur permission bertahap kini dijalankan sebelum service dimulai.
3. **Coarse-only location keliru dianggap ditolak.** Plugin geolocation sebelumnya
   membaca status gabungan alias permission. Pemeriksaan sekarang menerima grant
   `ACCESS_COARSE_LOCATION` atau `ACCESS_FINE_LOCATION` langsung dari Android.
4. **Firebase menolak update GPS untuk data legacy.** Service mendukung collection
   berbentuk array/key legacy, tetapi rules hanya mengizinkan write apabila key sama
   dengan Firebase UID. Rules sekarang juga memvalidasi field `uid` pada data lama
   atau data baru, tanpa membuka akses ke user lain.
5. **Artefak build dan signing belum diabaikan.** `.gitignore` ditambahkan agar cache,
   output build, konfigurasi SDK lokal, dan keystore tidak masuk repository.

## Validasi

- Syntax JavaScript entry integrasi diperiksa dengan `node --check`.
- Seluruh JSON dibaca dengan parser JSON dan seluruh resource/manifest XML dibaca
  dengan parser XML.
- `git diff --check` digunakan untuk memeriksa whitespace/patch.
- Build Gradle telah dicoba, tetapi runner audit memblokir akses ke
  `services.gradle.org` dan repository Google/Maven (HTTP proxy mengembalikan 403),
  serta tidak menyediakan Android SDK/dependency dalam cache. Karena itu assemble,
  unit test Android, dan lint harus dijalankan kembali pada Android Studio/CI yang
  memiliki SDK 35 dan akses dependency. Ini adalah keterbatasan runner, bukan error
  source yang berhasil direproduksi setelah perbaikan wrapper.

## Perintah build final

```bash
./gradlew clean test lint assembleDebug
```

APK debug akan dihasilkan di `app/build/outputs/apk/debug/app-debug.apk`.
